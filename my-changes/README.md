# my-changes — журнал изменений этого форка

Папка существует, чтобы через месяц или через год можно было за 10 секунд понять:
**что** изменено, **когда** и **где** (файл + строка), и **зачем**.

- Форк: https://github.com/tototolf/conky
- Оригинал (upstream): https://github.com/brndnmtthws/conky
- Базовая версия (fork point): `319260b7` — `feat(ci): publish ARM AppImages (#2497)`
- Ветка с изменениями: `main`

## Что внутри

| Путь | Что это |
|---|---|
| `README.md` | этот файл: сводка изменений и как их проверить |
| `CHANGELOG.md` | журнал по датам: что, где (файл:строка), было → стало |
| `meta.json` | то же машиночитаемо: даты ISO, SHA коммитов, sha256 файлов |
| `diffs/*.patch` | готовые git-патчи (`git apply`, `patch -p1`) |
| `files/data-conky.conf` | изменённый конфиг из репозитория (попадает в сборку и в `conky -C`) |
| `files/local-conky.conf` | рабочий конфиг на ноутбуке (то, что реально на десктопе) |

## Сводка изменений

### 1. Фон окна: чёрный → серый (`#808080`)

`data/conky.conf` — встроенный конфиг по умолчанию: он компилируется в бинарник
(`BUILD_BUILTIN_CONFIG` → `bin/text2c.sh` → `defconfig.h`) и печатается командой
`conky -C`. Настройка цвета фона в нём отсутствовала, поэтому фон окна был чёрным —
это умолчание, зашитое в код (`own_window_color = 0`).

| | |
|---|---|
| Файл | `data/conky.conf`, строка **45** (после правки) |
| Было | настройка отсутствовала → фон по умолчанию чёрный |
| Стало | `own_window_color = '#808080',` |
| Коммит | `107b4197` — `feat(config): default window background gray instead of black` |

### 2. Фон виджета на ноутбуке: серый → прежний (откат)

Тот же цвет был применён к рабочему конфигу на ноутбуке, а затем **возвращён к
прежнему** по просьбе владельца — серый не подошёл.

| | |
|---|---|
| Файл | `~/.config/conky/conky.conf`, строка **32** (копия — `files/local-conky.conf`) |
| Было | `own_window_colour = '1D2129',` |
| Стало 2026-10-15 15:32:36 | `own_window_colour = '808080',` |
| **Текущее состояние** (откат 15:40:06) | `own_window_colour = '1D2129',` — прежний фон |
| Коммит | нет: файл лежит вне репозитория |
| Дифф отката | `diffs/0002-local-config-revert-background.diff` |

Итог: **в проекте** (`data/conky.conf`) фон остался серым, **на ноутбуке** — прежний.
Копия `files/local-conky.conf` всегда отражает текущее состояние файла на машине.
Там используется британское имя `own_window_colour` — почему, написано ниже.

## Как проверить изменения

```bash
# 1. Что этот форк добавил поверх upstream
git log --oneline upstream/main..main

# 2. Само изменение построчно
git show 107b4197

# 3. История самого журнала
git log --oneline -- my-changes/

# 4. Применить патч на чистой копии upstream
git checkout -b test-apply -t upstream/main
git apply my-changes/diffs/0001-default-background-black-to-gray.patch

# 5. Что печатает собранный conky
conky -C | grep own_window_color

# 6. Дифф отката локального конфига (читаемый, не git-патч)
cat my-changes/diffs/0002-local-config-revert-background.diff
```

## Детали, чтобы не запутаться потом

1. **`own_window_color` и `own_window_colour` — одно и то же.**
   Современное (американское) имя — `own_window_color`, британское
   `own_window_colour` оставлено как устаревший алиас.
   - в репозитории (`main`, ветка 1.25.x) — новое имя `own_window_color`;
   - в конфиге на ноутбуке — старое `own_window_colour`, потому что установленный
     там conky **1.24.2** нового имени ещё не знает (проверено:
     `git show v1.24.2:src/output/gui.cc`).
2. **Формат цвета у Conky:** `#RGB`, `#ARGB`, `#RRGGBB`, `#AARRGGBB` —
   альфа идёт **первой** (`'#80808080'` = альфа 0x80 + серый). Шестизначный
   `#808080` — непрозрачный серый; короткая запись без альфы прозрачности не даёт.
3. **Прозрачность.** В репозитории фон сделан непрозрачным — ровно одна строка,
   только цвет. В локальном конфиге полупрозрачность сохранена как была
   (`own_window_argb_value = 150`); для плотного серого поставьте `255`.
4. **Исходники C++ (`src/**`) не тронуты.** Правка умолчания в коде повлияла бы
   на все конфиги сразу, включая чужие; изменён только шаблон конфига по
   умолчанию — минимальная и предсказуемая правка. Если понадобится поменять
   именно зашитое умолчание, это будет отдельное изменение (и отдельная запись здесь).

5. **Папка с патчами называется `diffs`, а не `patches` — это не случайность.**
   В `.gitignore` проекта есть правило `patches/` (строка 5), и любой каталог с
   таким именем молча исключается из коммитов: файлы на диске есть, а в
   репозиторий не попадают. Именно это и произошло при первом коммите журнала.
   Чтобы не бороться с `.gitignore` через `git add -f`, каталог переименован в
   `diffs`. Если будете добавлять свои патчи — кладите их сюда же.

## Обновление из upstream

Ветка `main` теперь содержит собственный коммит, поэтому кнопка **Sync fork**
на GitHub будет предлагать его отбросить. Правильный порядок:

```bash
git fetch upstream
git rebase upstream/main          # перенести свои изменения на свежий upstream
git push --force-with-lease       # свой форк — force безопасен
```
