# Журнал изменений форка

Сначала новые. Формат записи: **дата** → что сделано → где (`файл:строка`) →
было → стало → коммит. Копии изменённых файлов лежат в `files/`, патчи — в `diffs/`.

---

## 2026-10-15 15:40 — Фон на ноутбуке: откат к прежнему

**Итог.** Фон рабочего виджета на ноутбуке возвращён к прежнему (`#1D2129`).
Фон в проекте (`data/conky.conf`) оставлен серым — так решил владелец форка.

| # | Где (файл:строка) | Было | Стало | Коммит |
|---|---|---|---|---|
| 1 | `~/.config/conky/conky.conf:32`<br>(копия: `files/local-conky.conf`) | `own_window_colour = '808080',` | `own_window_colour = '1D2129',` | нет — файл вне репозитория |

**Зачем.** Серый фон не подошёл; прежний вид возвращён.
**Как проверено.** Файл побайтово совпал с резервной копией, снятой до изменения:
`diff` без различий, sha256 `c14a8e2f…` с обеих сторон, 94 строки, вхождений `808080` — 0.
**Дифф отката.** `diffs/0002-local-config-revert-background.diff`.
**Что НЕ изменялось.** Фон в проекте (`data/conky.conf`, коммит `107b4197`) — остался серым.

## 2026-10-15 15:31 — Фон окна: чёрный → серый

**Итог.** Фон окна Conky стал серым (`#808080`) вместо чёрного: и в конфиге по
умолчанию внутри проекта, и в рабочем виджете на ноутбуке (на ноутбуке позже
возвращён к прежнему — см. первую запись).

| # | Где (файл:строка) | Было | Стало | Коммит |
|---|---|---|---|---|
| 1 | `data/conky.conf:45` | настройки не было → фон по умолчанию чёрный (`own_window_color = 0` в коде) | `own_window_color = '#808080',` | `107b4197` |
| 2 | `~/.config/conky/conky.conf:32`<br>(копия: `files/local-conky.conf`) | `own_window_colour = '1D2129',` | `own_window_colour = '808080',` | вне репозитория — файл на ноутбуке<br>**отменено** 2026-10-15 15:40, см. первую запись |

**Зачем.** Тёмный, практически чёрный фон окна заменён серым по просьбе владельца форка.

**Как проверено.**
- Конфиг отрендерен реальным `conky 1.24.2` в консольном режиме
  (`out_to_console = true`, `out_to_x = false`, `-i 3`) — все объекты вернули
  значения: температура CPU 49 °C, кулер 0 RPM, NVMe 33 °C, Wi-Fi
  `MGTS_GPON5_5030` 79 %, батарея `D 54%` / осталось 1 ч 48 мин, ОЗУ 2,58G/15,3G,
  диск `/` 11,0G/184G.
- Что печатает установленная версия «до» правки: `conky -C | grep own_window` —
  в настройках только `own_window`, `own_window_class`, `own_window_type`,
  `own_window_hints`, цвета фона нет (строка 45 в 1.24.2 отсутствует).

**Хеши (sha256).**
- `files/data-conky.conf` — `2a47fe136b991849a29ee95b1dc5ec122829ec00f419a623af5526c8d6fcf578`
- `files/local-conky.conf` — `493d91bec50dc25366a9f8a3d25f0b7236894e2b68bcbb70825e8bc16147c234`
- резервная копия локального файла до правки: `~/.config/conky/conky.conf.bak-20261015-153236`

**Что НЕ изменялось.** Исходный код C++ (`src/**`), переменные и структура
конфигов, версии и лицензии — правка ровно в одной строке на файл.

**Заметка про имя папки с патчами.** Патч лежит в `diffs/`, а не в `patches/`:
в `.gitignore` проекта есть правило `patches/` (строка 5), из-за которого файл
патча молча не попал в первый коммит журнала — на диске он был, а в репозиторий
не добавился. Каталог переименован, чтобы не использовать `git add -f`.
